> This is **not a web project** — it runs as a native desktop application using PHP.

- ✅ HUD rendering
- ✅ Main menu

## Prerequisites

- PHP 8.1+
- PHP-GLFW extension
- Composer

## Run

```bash
git clone https://github.com/bariscodefxy/Half-Life-PHP.git
cd Half-Life-PHP

composer install
php ./bin/start.php
```
